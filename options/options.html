Suno Receipts

Capture settings

Tune how much evidence the extension records while keeping all project logs local to Chrome extension storage until export.

Log verbosity

Minimal records major authorship events. Balanced adds UI edit intent. Detailed includes lower-level Suno request observations.

Project prompt

Ask before creating a project receipt when a generation starts and no active project is attached to the Suno tab.

Storage and exports

Chrome blocks silent writes to arbitrary local folders from extensions. Receipts persist locally in extension storage. CSV export downloads to a SunoReceipts folder under the browser download location; the target product default is shown below for a future native helper.

PDF timeline

Use the PDF button in the popup to open a styled timeline. Chrome's print dialog can save that report as a PDF.
